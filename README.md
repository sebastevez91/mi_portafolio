## 🛠️ Tecnologías

- **HTML5** — estructura semántica
- **CSS3** — diseño responsive, variables CSS, animaciones
- **JavaScript** — scroll reveal, menú mobile, navegación activa
- **Font Awesome 6** — iconografía
- **Google Fonts** — tipografías Bebas Neue + DM Sans
- **FormSubmit** — formulario de contacto sin backend

No requiere instalación ni dependencias.

```bash

```
